# Sign Up Screen

## Reference
Use `docs/references/auth-home-reference.png`.

## Target
Same visual system as Login with fields for name, phone, email, password, confirm password, terms checkbox, and green primary CTA.

## Rules
Reuse the same centered V3 auth scaffold, direct form surface, real logo system,
input/button style, spacing and footer link style as Login. Secondary auth
screens show a compact inline back header above the form.

Registration does not invent an address. A new customer can add the first
pickup address from Home or directly from booking step one; the first saved
address becomes the default automatically.
